Product concept: BookFlow
A modern PDF reading and annotation app inspired by the simplicity of Apple Books, but designed for Android phones and tablets.
Core stack
Platform: Android
Language: Kotlin
UI: Jetpack Compose + Material 3
Architecture: Clean Architecture + MVVM
DI: Hilt
Database: Room
Preferences: DataStore
Async: Coroutines + Flow
Navigation: Navigation Compose
Storage: Android Storage Access Framework
Images: Coil
PDF Engine: PDFium-based engine / capable PDF SDK abstraction
Min Android: Android 10+
Target: Latest stable Android SDK

Important: create a PdfEngine abstraction. Don't tightly couple the application to one PDF library. Text selection, coordinates, annotations, links, search and rendering requirements may eventually require changing engines.

Phase 2 — PDF Import & Library
Implement proper document management.
Implement PDF import using Android Storage Access Framework.

Requirements:

- Open PDF from device
- Import one or multiple PDFs
- Persist URI permissions where appropriate
- Extract filename
- Extract metadata when available
- Determine page count
- Generate first-page thumbnail
- Store book metadata in Room
- Detect duplicate imports
- Recently opened
- Favorites
- Delete from library without deleting original file
- Optional explicit delete-file action with confirmation
- Grid/list library
- Search books
- Sort:
    title
    recently opened
    date added
    reading progress

Create Collections.

A book can belong to multiple collections.

Do not copy large PDFs into internal application storage unnecessarily.

This last point matters. A 1 GB PDF library shouldn't become another 1 GB app-data copy unless the user specifically requests managed copies.
Phase 3 — Core PDF Reader
This is the most important phase.
Create production-quality PDFReaderScreen.

Features:

- High quality page rendering
- Lazy page loading
- Vertical continuous scrolling
- Single page mode
- Horizontal page navigation
- Pinch zoom
- Double-tap zoom
- Pan while zoomed
- Current page indicator
- Jump to page
- Previous/next page
- Full-screen reading
- Show/hide controls by tapping page
- Restore last reading position
- Save reading progress automatically
- Page thumbnails
- PDF outline/table of contents
- Internal PDF links where supported

Optimize rendering for large PDFs.

Never render the entire PDF into memory.

Use page caching and release off-screen page resources.

Create PdfEngine interface so the underlying PDF implementation can later
be replaced without rewriting reader UI/domain logic.

For a 500-page medical or aviation book, lazy rendering and caching are critical.
